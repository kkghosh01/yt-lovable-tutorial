# yt-lovable-tutorial

📋 Main Prompt (Copy করো)
Create a modern, professional SaaS landing page for 
an AI productivity tool called "NexoraMind".

Design Requirements:
- Dark theme with deep navy (#0D1117) background
- Electric blue (#3B82F6) and purple (#8B5CF6) accents
- Clean, modern typography
- Smooth scroll animations
- Fully responsive (mobile + desktop)

Sections to include:
1. Navbar — logo left, nav links center, "Get Started" 
   CTA button right (sticky on scroll)

2. Hero — bold headline "Work Smarter with AI", 
   subtext, two CTA buttons (Primary + Secondary), 
   floating dashboard mockup image

3. Trusted By — logos of 5 fake companies 
   (grayscale, scrolling marquee)

4. Features — 6 feature cards with icons:
   - AI Writing Assistant
   - Smart Analytics  
   - Team Collaboration
   - Auto Scheduling
   - Code Generator
   - 24/7 Support

5. How It Works — 3 steps with numbered badges:
   Step 1: Connect your tools
   Step 2: Let AI analyze
   Step 3: Get results instantly

6. Pricing — 3 plans:
   - Starter: Free
   - Pro: $19/month (highlighted as popular)
   - Enterprise: $49/month

7. Testimonials — 3 cards with avatar, name, 
   role, and review text

8. FAQ — 5 questions accordion style

9. CTA Banner — "Start Free Today" full width 
   gradient section

10. Footer — logo, links, social icons, 
    copyright

Extra features:
- Dark/Light mode toggle in navbar
- Smooth hover effects on all cards
- Gradient text on headline
- Floating animation on hero image

🔧 Refine Prompts (একটা একটা করে)
Generate হলে এই follow-up prompts দিয়ে refine করো:
Navbar ঠিক করতে:
Make the navbar sticky with a blur backdrop effect 
when scrolling. Add smooth transition.
Hero আরো impressive করতে:
Add a gradient glow effect behind the hero mockup. 
Make the headline text have a gradient from 
blue to purple.
Animation add করতে:
Add fade-in scroll animations to all sections. 
Cards should animate with a slight upward motion 
when they enter the viewport.
Mobile responsive:
Check and fix mobile responsiveness. 
Navbar should become a hamburger menu on mobile.
